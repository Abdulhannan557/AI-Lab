# AI Lab

Welcome to my **Artificial Intelligence Lab** repository. This repository contains practical lab work completed using Python and Google Colab as part of my university AI Lab course.

## Objectives

- Practice Python programming fundamentals used in Artificial Intelligence.
- Implement AI search algorithms and understand how they explore possible solutions.
- Explore introductory machine learning concepts through small, reproducible examples.
- Keep each lab organized in a separate Jupyter notebook.

## Repository Structure

```text
AI-Lab/
├── README.md
├── Lab-01.ipynb
├── Lab-02.ipynb
└── ...
```

Each `Lab-XX.ipynb` file is a Jupyter notebook that can be opened and run in Google Colab.

## Tools

- Python 3
- Google Colab / Jupyter Notebook
- GitHub

## How to Run a Lab

1. Open the required `.ipynb` notebook on GitHub.
2. Click **Open in Colab** if available, or open [Google Colab](https://colab.research.google.com/) and upload the notebook.
3. Run the code cells from top to bottom.
4. Read the comments and markdown explanations, then try the practice tasks.
5. Save any updates back to this repository.
